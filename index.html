Shared Agents gog

A private Google Workspace command-line integration for its owner's personal AI assistants. This is not a public sign-up service.

The tool lets the owner use authorized Gmail, Calendar, Drive, Docs, Sheets and Slides features through a shared local gog installation. Actions depend on the permissions granted by the owner and the instructions given to each assistant.

Privacy notice

This integration accesses only the Google account authorized by its owner. Its granted capabilities include reading and sending email and reading or changing calendars, files, documents, spreadsheets and presentations. Granting access does not mean every resource is automatically retrieved.

Google data is used to carry out the owner's requested assistant tasks. Data retrieved for a task may be included in the context sent to the AI provider selected for that assistant and may be retained in the owner's local agent history, memory or task files. Content sent, shared or written to Google services follows the owner's task instructions.

OAuth credentials are stored in the owner's private server environment using gog's file keyring. The local operating-system account and server administrator can access that environment. Credentials are shared by the owner's compatible agent tools, rather than copied into each assistant profile.

The owner can revoke this integration in Google Account third-party access settings. Revocation prevents subsequent authorized access but does not automatically remove data already present in local agent records or content previously sent or shared. Local retained data must be removed separately by the owner.

This static page contains no analytics scripts or forms. A hosting provider may process normal web request logs. The support email shown on Google's consent screen is the contact for this privately operated integration.

Use terms

This tool is for the owner's personal use. It provides no public service or availability guarantee. The owner controls authorization and is responsible for reviewing consequential actions. This page describes the integration; it does not grant access to the owner's account or assistants.
